# ProofNotary

ProofNotary is a decentralized AI-assisted claim verification application built with GenLayer Intelligent Contracts.

Users submit a factual claim together with a source URL. The ProofNotary Intelligent Contract retrieves the source content, evaluates whether the source supports the claim, reaches a GenLayer consensus result, and stores the verification output on-chain.
